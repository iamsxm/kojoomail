# 写信编辑与 Markdown 表格

写信面板提供「可视化」「Markdown」「发送预览」三个入口。

- 已有 Markdown 草稿会直接读取；打开或切换预览不改写原文。可继续在 Markdown 模式编写邮件。
- 可视化工具栏支持标题、粗体、斜体、下划线、删除线、列表、引用、链接、表格和撤销重做。
- 选中文字后，可直接选择字体、字号、文字颜色和文字背景色；不选中文字时，设置应用于之后输入的文字。字体提供微软雅黑、宋体、黑体、楷体、仿宋、Arial、Times New Roman、Georgia 和等宽字体，字号为 10–96 px 的常用档位。实际显示使用收件人设备上的可用字体，并提供 Windows/macOS 字体回退。
- 两个颜色按钮分别调整文字与背景，提供预设色块、系统取色器以及 `#RGB` / `#RRGGBB` 自定义颜色。选「默认字体」「默认字号」「自动颜色」或「无背景色」可单独恢复默认；「清除格式」同时清除文字格式。选区包含不同样式时，工具栏显示混合状态。
- 插入表格时选择网格大小；在单元格中可加行、加列、删除行列、合并或拆分单元格，并拖动列边缘调宽。也可直接填写列宽，按 Enter 或点击「应用列宽」，留空恢复自动宽度。
- 普通内容继续保存为 Markdown。列宽、合并单元格、多段落表格采用 Markdown 内嵌 HTML 保存，重开草稿后保留这些信息。
- 字体、字号和颜色使用 Markdown 内嵌的样式片段保存，可与粗斜体、链接及表格组合；切换模式、保存并重开草稿后继续保留，发送时保留对应内联样式。
- 自定义 HTML 排版默认进入源码模式。切换到可视化编辑前会提示格式规范化，避免直接丢失不支持的样式。

正文右侧的缩放按钮可将显示调整到 75%–200%，不改变邮件的发送字号。「专注正文」收起地址、主题和 AI 侧栏，为编辑区留出空间。

拖动面板标题可移动写信面板，双击标题或点击最大化按钮可放大；右下角手柄可调整尺寸。居中按钮恢复默认位置与大小。标题获得键盘焦点后，方向键移动、Home 居中、Enter 或空格切换最大化；尺寸手柄获得焦点后，方向键调整大小。

Markdown 表格发送时自动附带内联边框、单元格间距与列对齐样式，避免外部邮箱只显示无边框内容。预览、普通发信与 MCP 发信继续使用同一个后端渲染器。HTML 签名和引用原邮件保持各自的布局。
